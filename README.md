# 灵魂魔性画师 · MOXING DRAW

一个 **“输入一段描述 → 秒出魔性神图”** 的纯前端图片生成小程序。  
零依赖、开箱即用，自带离线「灵魂画师」魔性手绘生成引擎，同时也支持填入 Gemini API Key 切换真 AI 魔性生图模式！

## 主要功能

- **🧠 中文/英文脑洞语义识别**：自动拆解描述里的**角色**（猫、狗、柴犬、熊猫头、打工人/程序员、老板、霸王龙、大鹅、青蛙、咸鱼、外星人、机器人、奥特曼、幽灵、猪、坤鸡等 18+ 魔性角色）、**双角色互动**（骑着、打架、追赶、吃、贴贴）、**动作情绪**（哭成喷泉、躺平睡觉、疯狂蹦迪、加班冒烟、发财钞票雨、飞天喷火）、**道具**（墨镜、皇冠、激光剑、奶茶、拖把、电脑、电瓶车）和**场景**（火星/太空、赛博霓虹、海边、办公室、草原、夜市、火山爆炸、催眠彩虹）。
- **🎨 5 大魔性画风一键切换**：
  1. 暴走灵魂手绘（抖动粗黑线 + 夸张颜艺）
  2. 精神污染表情包（经典放射线 + 上下黑边梗字）
  3. 鬼畜复古像素（低清像素化 + RGB 色差故障）
  4. 赛博霓虹崩坏（荧光反色感 + CRT 扫描线）
  5. 抽象毕加索（扭曲五官 + 满屏魔性弹幕贴纸）
- **🌶️ 魔性浓度滑杆 & 鬼畜抖动预览**：从“略微离谱”一路拉到“精神状态彻底放飞”，还能开启实时的帧动画鬼畜抖动预览。
- **💾 一键导出**：支持下载 `640×640` PNG 原图、复制图片到剪贴板、历史作品回看。
- **🤖 可选真 AI 生图**：支持在页面填入个人 Gemini API Key（仅保存在本地浏览器），调用官方 Gemini 图像接口生成魔性暴漫风格真 AI 图并叠加配文。

## 快速使用

直接双击根目录下的 `index.html` 即可在浏览器运行！
