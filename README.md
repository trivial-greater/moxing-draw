# 灵魂魔性画师 v2.0 · MOXING DRAW

一个 **“输入任意描述 → 真 AI 秒出魔性神图”** 的纯前端图片生成小程序。  
零依赖、开箱即用，默认接入**免费免 Key 真 AI 文生图引擎**，能真正理解任意脑洞（如「数学家梵高」「爱因斯坦在菜市场砍价」「秦始皇骑电瓶车送外卖」），并自动叠加魔性画风、梗字配文和弹幕贴纸！

## 核心能力

- **🤖 免费真 AI 生图（免 API Key · 默认）**：自动调用 Pollinations AI 将任意中文/英文描述扩写成爆笑夸张的魔性绘图提示词，生成真正贴合描述的图像，再叠加后期滤镜、魔性贴纸和梗字配文。
- **🔑 多平台自定义 API 支持（全部在浏览器本地直连，Key 不上传第三方）**：
  - 🇨🇳 **硅基流动 SiliconFlow**（国内直连，免费中文模型 `Kwai-Kolors/Kolors` / `FLUX.1-schnell`）
  - 🌸 **Pollinations 高速 Key**（GitHub 登录免费领取）
  - 💎 **Google Gemini**（`gemini-2.5-flash-image`）
  - 🔧 **任意 OpenAI 兼容中转站**
- **🎨 5 大魔性画风**：暴走喜剧漫、精神污染梗图、鬼畜复古像素（RGB 错位）、赛博霓虹崩坏（CRT 故障扫描）、抽象毕加索。
- **🌶️ 魔性浓度 & 实时后期**：自由调节贴纸/速度线浓度、开启鬼畜抖动预览、一键下载 `640×640` PNG 原图、历史作品回看。
- **🤪 纯离线涂鸦兜底**：断网时也可切到纯本地 Canvas 模式体验。

## 快速使用

直接双击根目录下的 `index.html` 即可在浏览器运行！
